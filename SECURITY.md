# Security policy

## Reporting a vulnerability

Report a security issue privately through GitHub Security Advisories for this repository:

https://github.com/pkolasin/WorkerKit/security/advisories/new

Do not open a public GitHub issue for a vulnerability, and do not put exploit details in a public discussion. A report should describe the affected package or component, the version or commit, and the impact.

This repository will acknowledge the report and coordinate a fix before any public disclosure.
