# WorkerKit.Soap

Generic WCF helpers for a WorkerKit connector:

- `SoapChannel.CreateBasicHttpBinding` builds a `BasicHttpBinding` from an absolute endpoint and a timeout
- `SoapChannel.AbortUnlessCompleted` aborts a channel that was not closed

Generated service contracts stay in the connector. This package does not contain a generated client.

Repository: https://github.com/pkolasin/WorkerKit
